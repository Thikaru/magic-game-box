# 連結回避!ツインオービット  (2026-08-06 / twin-orbit-dodge)

## 1. ワンライン
避けゲーが得意なプレイヤーが、自分では1点しか動かしていないのに、
回転する棒の両端をせまい隙間へ同時に滑り込ませて「間に合った」と胸をなでおろす、
1点操作・2点被弾の避けゲーム。

## 2. コアメカニクス（1つだけ）
自機は「常に一定速度で自動回転し続ける棒」の中心(ピボット)だけを操作でき、
被弾判定は棒の**両端2点**にある。プレイヤーは1点しか動かせないのに、
守るべきは常に2点(しかも回転で刻一刻と位置が変わる)、という操作と判定のズレが
このゲームの中心の仕組み。これを取り除く(=棒を1点の当たり判定に戻す)と、
ただの操作反転しない平凡な避けゲーになり成立しなくなる。

## 3. 新規性 — どこが「他にない」のか
- 掛け合わせた軸: メカニクス軸〈避けゲー/アクション〉×制約・仕掛け軸
  〈操作は1点だが被弾判定が2点に伸びている(自動回転する棒)〉+ 感情軸〈間に合った〉
- 一番近い既存ゲーム: 2026-07-19 重力リバースラン、2026-08-05 はねかえせ!エコーシューター
  などの単点(自機1点)の避け・操作ゲーム全般
- それと決定的に違う点: 単点の自機ではなく、常時回転する「棒」の両端が同時に
  被弾判定を持つため、回転位相(棒が細く見える瞬間/横に長く伸びる瞬間)を読んで
  移動先を決める必要がある。操作は単純(1点移動)なのに判定は複雑、という非対称性。
- 過去作（games-log.md / blueprints）との差分: ログ上、自機の当たり判定が
  「回転する2点」になっている作品はこれまでゼロ。単点回避・パドル(帯)回避・
  キャラ切替回避はあるが、回転する伸縮した剛体を回避判定に使う作品はない。
- 【却下チェック】ジャンル名だけで中身が説明できてしまわないか？ →
  「避けゲー」とだけ言っても「棒が自動回転して両端が判定になる」ことは
  一切伝わらないので No。

## 4. 心が震える瞬間（最重要）
- 対象プレイヤー: 反射神経系の避けゲームは得意だが、単点回避に少し物足りなさを
  感じ始めているプレイヤー
- 狙う感情を1つに絞る: 「間に合った」
- その感情が発火する具体的な瞬間: 弾の壁にできた1つの隙間へ向けて移動している最中、
  棒の回転位相がちょうど「隙間の幅にぴったり収まる角度」に噛み合って、
  ギリギリで両端とも無傷ですり抜けられた瞬間
- なぜ震えるのか（設計上の理由）: プレイヤーは移動先(ピボット位置)しか操作できず、
  回転角度そのものは操作できない。「今の角度なら間に合うか」を自分でコントロール
  しきれない不確実性が、成功時の「間に合った」という安堵を強くする
- この瞬間を確実に起こすための仕掛け: 弾の隙間の幅を、棒が最も細く見える位相
  （縦一直線に近い角度）ならギリギリ通れるが、横に伸びた位相だと通れない
  絶妙な幅に調整する。これにより「移動タイミングと回転位相の噛み合い」を
  プレイヤーが毎回意識せざるを得なくする

## 5. 体験フロー（時間で設計する）
- 0〜10秒: 棒がゆっくり回転しながら、まばらな弾の壁(隙間広め)が落ちてくる。
  ドラッグ/矢印キーでピボットを動かすと棒ごと平行移動することがすぐ分かる
- 10〜60秒: 「棒の両端を同時に意識して隙間に合わせる」パターンを習得する
- 1〜3分: 回転速度が上がり隙間が狭まる。隙間が2箇所に分かれるパターンや
  斜めに流れる弾も出て、瞬時にどちらへ寄せるか判断する場面が増える
- 終了時: 生存タイムとスコア、ニアミス回数を見て「もう一回」を押したくなる

## 6. 学習の階段（Koster: 面白さ＝学習）
1. ピボットを動かすと棒ごと平行移動し、棒自体は常に回り続けていると気づく
2. 棒が縦向き(細い)の瞬間は隙間を通りやすく、横向き(太い)の瞬間は通りにくいと理解する
3. 隙間に到達する少し前から、通過時の回転位相を逆算して移動を先読みするようになる
4. 回転速度が上がっても、先読みのリードタイムを短く保てるようになる
5. 二重隙間パターンで、より安全な(通過時に棒が細くなる)側を瞬時に選べるようになる
- 習得し切った後に何が残るか: 生存タイム自己ベストの更新、ニアミス演出を
  狙って通る「際どい通過」のスタイル的な気持ちよさ

## 7. 意味のある選択（Sid Meier）
- 隙間が2箇所に分かれるパターンが出たとき、「近い方(移動距離が短く安全)」か
  「回転位相が噛み合う方(移動は長いが確実に細い状態で通過できる)」かを選ぶ
- 常に安全な選択肢が両立するわけではなく、移動距離を優先すると回転位相が
  合わずニアミス/被弾リスクが上がるトレードオフがある

## 9. フィードバック設計（ジュース）
- 視覚: 被弾時は画面を軽く揺らし赤フラッシュ、ニアミス（棒スレスレ通過）時は
  棒が一瞬きらっと光る、隙間を綺麗に抜けたら軌跡がうっすら残るトレイル演出
- 視覚（6bで追加）: 棒の横幅（2×半径×cos(角度)）が35px未満、つまり縦向きに近く
  隙間を通りやすい位相のとき、棒全体を黄色くグロー発光させる。回転位相という
  目に見えにくい状態量を常時可視化し、「なぜ通れた/当たったか」の納得感を強める
- 音: Web Audio API のオシレーター/ノイズで自前生成。被弾音（低音ノイズ）、
  ニアミス音（高音の短いピッ）、壁クリア時の小さな加点音、ゲームオーバー音
- 「気持ちよさ」の中心になる1つの演出: ニアミス時のきらっと光る演出と高音の
  「ピッ」。惜しい通過ほど強く光らせ、際どさそのものを気持ちよくする

## 10. 失敗の納得感
- 負けた瞬間、プレイヤーは何を見て「自分のミスだ」と理解するか: 被弾した端の
  位置に赤い衝突エフェクトが出て、どちらの端が・どの弾に当たったかが視覚的に明確
- 理不尽（予告なしの即死、隠れた乱数での敗北）が起きないことの確認: 弾壁は
  出現位置(画面上端)で必ず一定時間見えてから落下するため、隙間の位置は
  前もって視認できる。乱数は隙間位置と斜め方向にのみ使い、当たり判定自体に
  不可視要素はない
- 「惜しい負け」を意図的に作る仕掛け: 隙間幅は「棒が最も細い位相なら通れるが、
  太い位相だと数px足りない」絶妙な幅に設定しているため、被弾は「あと少し
  タイミングがずれていた」という納得感のある際どさになりやすい

## 11. 非目標（作らないもの）
- 敵キャラクターやボスは作らない（弾の壁のみで構成する）
- 真の追尾(ホーミング)弾は作らない（斜め移動までに留め、理不尽さを避ける）
- スコアランキングやオンライン要素は作らない（ローカルの自己ベストのみ）
- 仮想コントローラ(vpad)は搭載しない。ドラッグ操作だけで完結するため
  CLAUDE.md 必須要件5「タップ・ドラッグ・スワイプで直接遊べるゲーム」に該当し、
  仮想コントローラは不要と判断（キーボードは矢印/WASDで別途フル対応する）

## 12. 検証ポイント（セルフレビューで確認する項目）
- [ ] 10秒で操作（ドラッグで棒ごと動く）が理解できる
- [ ] 3分遊んだ人が「棒の両端が回転しながら弾を避けるゲーム」と一言で説明できる
- [ ] 負けた理由（どちらの端がどの弾に当たったか）が本人にわかる
- [ ] 2回目のプレイに前回と違う体験がある（隙間パターン・斜め弾はランダム）
- [ ] 「4. 心が震える瞬間」（隙間×回転位相が噛み合ってすり抜ける瞬間）が
      実際にコード上で起こりうる

## 検討したが見送った案(6bで洗い出し)

- **二重隙間の片方を「移動は短いが位相が悪い」ことが分かるよう色分けする案**:
  視覚的な情報量が増えすぎて「読む」楽しさより「調べる」作業感が勝ると判断し
  見送った。現状どおり、プレイヤー自身の目で棒の向きと隙間を見比べて判断させる
  方が「6. 学習の階段」の狙いに合う。
- **回転を自機のドラッグ操作でも部分的に操作できるようにする案**(例: 素早く
  弾くと一瞬回転が加速する): 「1点しか操作できないのに判定は2点」というコア
  (2.)がぼやけるため見送り。将来、周回モードなどコアを維持したまま深さを
  足す拡張として再検討の余地はある。
- **被弾時のライフ減少に加えてスコアを一部減点する案**: 「失敗の納得感」は
  ライフ減少と視覚エフェクトで十分に成立しており、スコア減点まで足すと
  「もったいない」が強くなりすぎて「間に合った」という狙う感情の純度が下がる
  ため見送った。
