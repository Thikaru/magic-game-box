あそびかた

光ったマスの配置を数秒間だけ見て覚えよう。
消灯したら、同じ配置になるようマスをタップして再現!

ただし1回タップすると、そのマスと
上下左右のマスも一緒に光り方が反転する。
連鎖を逆算するのがコツ。

👆 タップ / 🖱 クリック でマスを反転
⌨ 矢印キーで選択 → Enter/Space で反転

使えるタップ回数には上限があり、
回数を使い切るか「はやめに判定」を押すと答え合わせ。

一致すれば次のレベルへ!残りタップが多いほど高得点。
まちがえるとライフが1減る(♥3つ)。
レベルが進むほど盤面が広がり、覚える時間も短くなる一発勝負!
